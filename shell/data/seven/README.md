# Windows 7 Start menu frames

The PNGs here are SevenStart's SVG frames from
[AeroThemePlasma](https://gitgud.io/wackyideas/aerothemeplasma) (GPL-3.0),
rendered to pictures: the white column, the search field, the hover boxes,
the split Shut down button and the picture frame. `StartMenuSeven.qml` draws
them as BorderImages when a Start menu style asks for Windows 7's layout
(`startmenu-layout=1`, `themes/startmenu/aero.conf`).

They were brought into Vela by lowell (Lowell137/vela) and keep
AeroThemePlasma's license, GPL-3.0.
